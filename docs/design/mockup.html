Design system — shipped with this mockup

Color tokens · authored in OKLCH, validated with WCAG

Measured on dark: text 16.28:1, muted 8.12:1, faint 5.33:1, all state colors ≥ 7.25:1, control border 4.17:1 (≥ 3:1, WCAG 1.4.11). Full tables + FASE-9 re-measurement: docs/design/PALETTE.md §4/§4.1.

Typography

Agent run title — 20 / 600
Section heading — 16 / 600
Body prose (human-readable) — 14 / 400, line-height 1.45
machine facts: run_id 0x9f1a · +262/−26 · $0.42 · 58.1k tok
label / eyebrow — 11 uppercase, tracking .02em

Sans = system stack for prose; mono = all machine facts (ids, paths, tokens, cost, hashes). System fonts honor the no-new-dependency boundary (RFC 66 §9.3).

State vocabulary (never color alone)

Each state pairs a color with a spine, a dot shape, an icon and a label, so it survives color-blindness and grayscale. Mapped 1:1 to the real AgentStatus enum, plus the proposed unknown (glyph ?, faint #868686, AA 5.33:1). ← spine = identity device: scanned peripherally without reading.

Keyboard focus · :focus-visible

Every control shows a 2px ring (--a-focus = teal, ≥3:1 per WCAG 1.4.11) on keyboard navigation. This was an open FASE-9 finding; the rule is now live in this mockup.
