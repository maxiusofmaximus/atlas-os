3 · Agent card anatomy (disclosure: layers 0–3)

LAYER 1 — always visible ● AgentX · researcher · model · 12m · 📌 mission › obj › task
status (spine+label) · diff +N/−M · cost
LAYER 0 — on COMPLETION (collapsed)
▸ Worked for 14m 22s · Thinking / Commands / Edits — auto-collapses when done (Zed); "?" glyph + faint = unknown state
LAYER 2 — expand
confidence + judgment · files touched · tool calls · skill · execution mode · modo uso
LAYER 3 — click
step timeline · evidence links · worktree/branch/dirty · checkpoint · reasoning trail
▶ Run⏸ Pause⏹ Stop🔱 Fork🚑 Recover💬 Steer👁 Reason🎬 Demo

Layer 1 never shows JSON; layer 3 never forces reading logs. Actions are gated by state (doom_loop ⇒ Recover/Override/Stop only). On completion the card collapses to Layer 0 ("Worked for Nm").
