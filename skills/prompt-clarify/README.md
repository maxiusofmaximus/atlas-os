# Prompt Clarify — script module (RFC 23 §7.2)

This skill is invoked when the Prompt Understanding Pipeline calculates a confidence below HIGH. It surfaces the top K clarification questions (default K=3) generated by STORM multi-perspective analysis (RFC 23 §2.1).

## Inputs

- `verdict_id` (string) — the published `PublicUnderstandingVerdict.id`.
- `max_questions` (number, optional, default 3)
- `perspectives` (string[], optional, default `["developer", "qa", "ops"]`)

## Outputs

Annotated ` telefonos: ClarificationQuestion[]` appended to the `PublicUnderstandingVerdict.clarification_questions` field (see RFC 23 §3).

## Behavior

1. Read `verdict_id` from the Journal.
2. For each perspective requested, call `kernel-prompt` (the reasoning model) with:
   - System prompt: perspective angle
   - User prompt: raw user prompt + `gaps[]` (each with type + evidence)
3. Filter the LLM responses to questions only (regex `^(\w+\s+){4,}\?\s*$`).
4. Deduplicate semantically via Vector KB (cosine > 0.72 -> dedupe).
5. Append to `verdict.clarification_questions`, mark `auto_resolved=false`, persist.
6. Emit `kernel.event(MissionUnderstandingUpdated)` so the HUD re-renders.
